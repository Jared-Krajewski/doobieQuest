# 🎮 DoobieQuest

A chill web based arcade-style game built with Phaser 3 in stunning **1080p**.

## 🎯 Game Overview

Play as **The Seeker** navigating three levels to collect the necessary items and cash for the ultimate quest reward.

### Levels

1. **Level 1: The Crib**
   - Collect **Money** scattered around the house
   - Find the **Lighter** in a random location within the house
   - Avoid dogs, toxic sludge, and crabs.
   - Navigate beds, dressers, TV stands, bookshelves, and floating platforms

2. **Level 2: The Convenience Store**
   - Use **$20** to purchase **Rolling Papers** at from the cashier
   - Avoid police patrols that fire guns, dogs and toxic sludge
   - Navigate candy, drinks, snacks, bakery, and deli sections


3. **Level 3: The Back Alley** (4500px wide)
   - Reach the **Dealer** (a towel with an affinity for marijuana) with **$50**, **Lighter**, and **Papers**
   - Avoid **Police Officers** patrolling the alley, rats, dogs, and toxic sludge
   - Navigate fire escapes, dumpsters, brick walls, and crate stacks
   - After buying weed, press **Q** to roll a **Doobie** and win!

## 🎮 Controls
### Keyboard
- **W A S D** or **Arrow Keys**: Move up/left/down/right
- **SPACE**: Melee attack (directional)
- **SHIFT**: Throw bongerang (returns after distance))

## 🚀 Quick Start

```bash
# Install dependencies
bun install

bun run dev
```

Then open http://localhost:5173 to play

## 🏗️ Tech Stack

- **Phaser 3.90** - Game engine with Arcade Physics
- **Tiled** - 2d mapping
- **Vite** - Fast dev server and bundling
- **Bun** - Fast package manager and runtime
